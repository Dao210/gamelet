# Patches 本地交付记录

日期：2026-09-07。新增 Patches 矩形拼图已接入当前 Gamelet 架构，首页第一张卡片可进入。原有 Pulsefront 工作保留。

## 实现

- 沿用 Next.js 路由、layout、导航页脚、next-intl、SEO helper 和统计函数。未修改公共架构、广告策略、数据库、题库 API、依赖版本或部署方式。
- 930 道自由练习、90 天三档每日挑战（270 道保留题）、12 道教学微关卡及 60 道精选训练。所有 1,212 道不同题面均唯一解，规范化去除旋转/镜像重复，且可沿存储的逻辑步骤完成。精选训练与练习题重用 ID，不虚增独立题目数。
- 支持拖动、反向绘制、两角点击、键盘方向与确认、取消、删除、撤销/重做、清空、暂停、分层提示、确认后查看解答。提示和解答会标记辅助完成。
- 本地保存当前题、已画区域、用时、提示次数和成绩；暂停时不计时。恢复时验证矩形合法性，多标签冲突由玩家选择棋盘，完成成绩保留双方最佳记录。损坏/禁用/配额不足的存储不阻止游玩。
- 稳定题号分享，同一分享题刷新可继续存档，结算后可重玩本题；首批每日排期为 2026-09-07 至 2026-12-05。页面标明设备 UTC、独立开发关系、有限题库及本地成绩边界。
- 主页面、三档难度、玩法和策略共 6 个入口，覆盖 en/zh/de/es/ja；沿用隐藏语言的现有回退策略，补齐 sitemap、canonical/hreflang。文章不加载游戏运行代码。

## 验证

- 全量 Jest：21 个套件、251 个测试通过，包含新增规则、加载、存档、计时、提示、键盘及异常存储回归。
- 题库：1,212 唯一解、1,212 逻辑证明、253 次独立求解器交叉检查，270 个每日 ID 无重复且排期连续。
- TypeScript、i18n、生产构建通过。ESLint 0 错误，28 个原有警告；新增文件无 lint 警告。公开五种语言翻译检查完整，隐藏语言原有 102 项缺失沿用现状。
- 本机 HTTP 检查：30 个公开页面为 200，30 个 sitemap 条目及 canonical 正确，不存在的难度为 404。初始 HTML 不包含完整题库。
- 浏览器：实际从首页进入，英文分享题可打开，反向键盘绘制、快捷键撤销/重做与取消有效，鼠标两角与拖动完成整局，覆盖 25/25、独立成绩与下一题正常；每日切换、72 步学习菜单、提示解释与显式放置、分享反馈、刷新恢复及辅助完成标记检查。控制台仅见原有 AdSense 的 data-nscript 警告，没有游戏 JavaScript 错误。
- 390px 手机视口下 8×8 格子全部为 41px，页面无横向溢出；保留当前公共脚本和导航。桌面验证为本机浏览器，未等同于真实低端手机验收。

## 性能边界

最终生产构建的 gzip 测量如下（字节）：

| 项目 | 字节 |
| --- | ---: |
| 游戏运行 JS | 8,935 |
| 24 个按需题包中的最大包 | 7,714 |
| Easy / Medium / Hard 首题配置 | 238 / 296 / 402 |
| 英文游戏页初始 HTML | 23,437 |
| 英文游戏页初始第一方 JS（含公共框架） | 268,334 |
| 英文玩法页初始第一方 JS | 259,399 |

题包没有合并进运行 JS；玩法和策略文章不含游戏运行包。第一方 JS 不包括外部广告/统计服务追加下载，测量时没有关闭这些公共脚本。可用 `pnpm puzzles:check-build` 在构建后重复检查运行 JS ≤45 KiB、首题 ≤5 KiB、题包 ≤40 KiB 的预算。

规则合法路径微基准 p95 约 0.0012 ms（本机 Node 24）。计时器独立于棋盘渲染，拖动预览每动画帧至多更新一次；下一题按需预取，保存合并到动作之后。

以上为本地逻辑/资产/浏览器功能证据，不宣称线上 Core Web Vitals 或弱网、低端设备的 INP/长任务已达标。当前浏览器检查工具不暴露 Performance API，未给出虚构的 LCP、INP、CLS 或切题到绘制延迟。整页既有公共脚本和语言包仍参与加载，本次不调整它们。
